## О проекте

Aiden Calculator выглядит и работает как привычный калькулятор. Помимо обычных вычислений, внутри приложения есть защищённое личное пространство, которое открывается только после ввода кода доступа или подтверждения биометрией.

В нём можно хранить фотографии, видео и документы, не выставляя личные файлы напоказ в общей галерее устройства.

## Основные возможности

- обычный и инженерный калькулятор с историей вычислений;
- приватное хранилище для фото, видео и документов;
- вход по коду доступа или биометрии;
- два независимых пространства: основное и дополнительное;
- импорт, просмотр, экспорт и удаление файлов;
- корзина с возможностью восстановления;
- встроенный приватный браузер;
- передача файлов по Wi-Fi и резервное копирование через WebDAV;
- защита от скриншотов и быстрая блокировка приложения;
- светлая и тёмная темы, русский и английский языки;
- несколько вариантов значка приложения.

## Идея проекта

Главная цель — объединить повседневный инструмент и личное хранилище в одном аккуратном приложении. Пользователь получает знакомый интерфейс калькулятора, а личные данные остаются в отдельном защищённом пространстве.

Приложение хранит данные локально. Передача или резервное копирование выполняются только по действию пользователя.
